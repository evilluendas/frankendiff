## What it is

Frankendiff is a public, statically-generated reading tool for Mary Shelley's *Frankenstein*. It presents the 1818 first edition and the 1831 revised edition and makes the differences between them visible inside the flow of the novel itself. It is aimed at readers, students, and anyone curious about how the text changed, without requiring a scholarly edition.

The editorial stance: the contrast worth telling is between the raw 1818 text and the heavily revised 1831 text. The 1823 second edition (mainly typographical fixes, first to carry Shelley's name) is deliberately out of scope.

## Goals

1. **Read either edition, chapter by chapter**, with an edition switcher that keeps the reader on the same chapter when flipping between 1818 and 1831. The chosen edition is remembered (cookie) across pages.
2. **See exactly what changed** in a Diff view: both editions merged paragraph by paragraph, insertions and deletions highlighted inline. Direction is always 1818 → 1831.
3. **Editorial reading experience**: generous whitespace, serif body text, drop caps, ornaments, custom covers, light and dark themes, unobtrusive navigation (sticky chapter nav, floating chapter picker).
4. **Fast and cheap**: fully static pages, minimal client JavaScript, all heavy lifting done at build time.
5. **Faithful text**: paragraph structure, poems, letter salutations/datelines/signatures, and italics preserved per edition.

## Non-goals (current)

- A side-by-side column view (built early, removed 2026-03-13 as not useful).
- Including the 1823 edition.
- Any database, CMS, or runtime content API.
- User accounts, comments, or server-side personalization.

## Architecture (inferred from the code)

### Content pipeline (build time)

```
content/original/{1818,1831}/*.xhtml   Wikisource Parsoid exports (archival; used once)
        │  scripts/extract-html.ts      one-time bootstrap → Markdown with [tag] markers
        ▼
content/raw/{1818,1831}.md             CURATED SOURCE OF TRUTH — hand-corrected since extraction
        │  scripts/parse.ts             sections → BookParagraph[] (elementType from [tag] markers)
        │  scripts/align.ts             positional alignment anchored by identity pins in
        │                               content/alignment-overrides.json (rows; 1:1, 1:2, 2:1 or
        │                               edition-only); 1818 volume slugs → canonical
        │                               slugs via content/edition-alignment.json; content/diff-units.json
        │                               diffs a chapter against several sections of the other edition
        │                               (1818 Ch I vs 1831 Ch I–II) and marks where each section begins
        │  scripts/align-report.ts      `npm run align:report` — flags likely misaligned rows
        │  scripts/diff.ts              clause-anchored, word-level weighted LCS diff → DiffOp[]
        │  scripts/build.ts             orchestrates; builds ChapterMeta index
        ▼
content/processed/chapters.json, ch<slug>.json   gitignored, regenerated by `npm run preprocess`
```

`content/chapter-structure.json` drives the homepage/navigation table (rows with per-edition labels, volume breaks, split notes).

### Runtime app (Next.js 16 App Router, all static)

| Route | Purpose |
|---|---|
| `/` | Homepage: edition browser, chapter table, project intro |
| `/[edition]/chapter/[chapter]` | Read one edition (`/1818/chapter/22`); edition switcher. Legacy `/chapter/[chapter]?edition=` 308s here |
| `/diff/[chapter]` | Inline diff of 1818 → 1831 |
| `/about` | Editorial background on the editions and why 1823 is excluded |

- `lib/data.ts` reads processed JSON synchronously at build time; `lib/types.ts` holds the shared types; `lib/utils.tsx` holds rendering helpers (e.g. italics).
- Server Components by default. Client components: `ThemeToggle`, `EditionBrowser`, `EditionCookieSync`, `HomepageContent`, `StickyChapterNav`, `StickyReveal`, `ChapterNavFAB`.
- Styling: Tailwind v4 with a custom theme in `app/globals.css`; fonts via `next/font` (Lora body, Inter UI, Manufacturing Consent and Pinyon Script for display/ornament); Lucide icons.

### Data model

- `BookParagraph { id, edition, chapter, paragraphIndex, text, elementType }`
- `AlignedParagraphGroup { chapter, paragraphIndex, alignmentKey, paragraphs: {1818?: BookParagraph[], 1831?: BookParagraph[]}, diffs: {"1818_1831": DiffOp[]}, sectionStart? }` — a row holds one paragraph per edition, or several when one edition split or joined paragraphs the other kept whole (the diff runs over the paragraphs joined by a break)
- `ChapterMeta { slug, order, title, editions, labelsByEdition? }`

Canonical slugs follow 1831 numbering (`1`…`24`) plus shared sections (`cover`, `introduction`, `preface`, `letter-i`…`letter-iv`, `walton-in-continuation`).

### Deployment & observability

- Vercel, production from `trunk`, previews from PRs. `npm run build` includes preprocessing.
- Vercel Analytics and Vercel Speed Insights (Plausible dropped 2026-08-24).
